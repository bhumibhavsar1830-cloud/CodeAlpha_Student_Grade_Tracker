# Student Grade Tracker – Java

## 📌 Internship
**Company:** CodeAlpha  
**Role:** Java Programming Intern  
## 📌 Project Description
This is a console-based Java application developed as part of the CodeAlpha Java Programming Internship.
The application allows users to:
- Add student records
- Calculate percentage
- Assign grades
- Determine pass/fail status
- Display a summary report including average, highest, and lowest marks
## 📌 Technologies Used
- Java
- ArrayList
- Scanner Class
## 📌 Grading System
| Marks | Grade |
|------|-------|
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| Below 60 | F |

**Pass Criteria:**  
Percentage ≥ 35 → Pass  
Percentage < 35 → Fail
